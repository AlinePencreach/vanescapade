# StatusTimeline

Historique des statuts d'une réservation, visible par le client une fois la réservation confirmée.

- **Fournir** : la liste ordonnée des statuts avec date, heure et, côté équipe, l'employé et les relevés (kilométrage, carburant).
- Passé = pastille pleine + coche ; en cours = pastille contour + icône ; à venir = pointillés et texte `ink-muted`. Liste ordonnée (`ol`) pour les lecteurs d'écran.
