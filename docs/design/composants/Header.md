# Header

En-tête du site : logo typographique à gauche, navigation (Accueil, Nos vans, Contact) en puces arrondies, bouton secondaire « Se connecter » (ou « Mon espace » une fois connecté).

- Page active : `aria-current="page"` + fond `action-soft` + graisse 600.
- Mobile : logo + bouton menu 44 × 44 avec `aria-expanded` ; le menu s'ouvre en panneau plein écran avec les mêmes entrées.
- Espaces employé / administrateur : même en-tête, entrée « Tableau de bord » ajoutée selon le rôle.
