# Alert

Message en ligne `ve-alert--{info|success|warning|error}` : fond `*-soft`, texte `*-ink`, icône dédiée.

- **Fournir** : une phrase qui dit ce qui se passe et quoi faire ensuite ; le gras pour l'essentiel seulement.
- `role="status"` pour l'information et le succès, `role="alert"` pour l'erreur (ex. conflit de réservation détecté côté serveur au moment de valider).
